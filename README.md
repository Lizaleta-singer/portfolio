# Елизавета Сиволобова — Вокал и Актёрская школа

Сайт-визитка юной певицы и актрисы. Современный, яркий, с анимациями и динамической галереей фото.

## Структура проекта

```
music/
├── src/
│   ├── main.tsx              # Точка входа
│   ├── App.tsx               # Корневой компонент
│   ├── App.css               # Глобальные стили и анимации
│   ├── index.css             # Сброс стилей, CSS-переменные
│   └── components/
│       ├── Header/           # Навигация (sticky header)
│       ├── Hero/             # Главный экран с анимацией
│       ├── About/            # Секция "Обо мне"
│       ├── Gallery/          # Динамическая галерея фото
│       ├── Achievements/     # Достижения (timeline)
│       ├── Contact/          # Контакты и соцсети
│       └── Footer/           # Подвал сайта
├── public/                   # Статические файлы
├── package.json              # Зависимости + скрипты
├── vite.config.ts            # Конфиг Vite (base: /music/)
└── tsconfig.json             # TypeScript конфиг
```

## Установка и запуск

```bash
# Установка зависимостей
yarn install

# Режим разработки (горячая перезагрузка)
yarn dev

# Продакшн-билд
yarn build

# Превью продакшн-сборки
yarn preview
```

## Развёртывание на GitHub Pages

1. Создайте репозиторий на GitHub
2. Настройте `base` в `vite.config.ts` (сейчас стоит `/music/`)
3. Добавьте скрипт деплоя или вручную:

```bash
yarn build
# Копируйте содержимое папки dist/ в ваш репозиторий
# Или используйте gh-pages пакет:
npx gh-pages -d dist
```

Или настрой GitHub Actions — файл `.github/workflows/deploy.yml` можно добавить для автоматического деплоя.

## Технологии

- **React 18** с хуками (useState, useEffect, useCallback, useRef)
- **TypeScript** — строго типизированный код
- **Vite** — быстрый билдер и dev-server
- **Yarn** — пакетный менеджер
- **CSS** — отдельные файлы стилей для каждого компонента
- Без дополнительных зависимостей: анимации и слайдер на чистом CSS + React

## Особенности

- Полностью адаптивный дизайн (mobile-first)
- Анимированный градиентный фон на главном экране
- Динамическая галерея автопроигрывания с паузой при наведении
- Свайп на мобильных устройствах
- Клавиатурная навигация стрелками
- Плавное появление элементов при скролле (IntersectionObserver)
- Бургер-меню для мобильных устройств

## Как заменить контент

Фото в галерее находятся в `src/components/Gallery/Gallery.tsx` — массив `photos`.
Замените URL на свои фотографии. Профильное фото — в `src/components/About/About.tsx`.

`.github/workflows/deploy.yml` — готовый воркфлов для автоматического деплоя на GitHub Pages.

Как это работает:

|Стадия|Что делает|
|---|---|
|build|Checkout → установка Node.js 20 → yarn install → yarn build (Vite) → загрузка артефакта (dist/)|
|deploy|Деплой артефакта на GitHub Pages через actions/deploy-pages@v4|

Триггеры:

1. Автоматический — при пуше в ветку main
1. Ручной — через кнопка Actions → Run workflow (или workflow_dispatch)

Для активации деплоя на GitHub:

1. Перейти в Settings → Pages → Source: GitHub Actions
2. Пушнуть код на main — воркфлов запустится автоматически
3. Или вручную нажать Run workflow на странице Actions
